# BibleReader v5

Complete BibleReader Expo project.

Includes the Bible reading features built in the working App.js:
- 66-book Bible architecture
- Bible search
- bookmarks
- highlights
- notes
- reading history
- verse sharing
- audio Bible button
- book/chapter picker
- daily verses
- reading plans
- dark mode
- font-size controls

For Expo Go, use an SDK 57-compatible environment.
